# 📊 SQL Excel Dashboard Project

## 📌 Overview
This project demonstrates a basic end-to-end data analysis workflow using **SQL and Excel**.  
It converts raw sales data into meaningful insights using queries, pivot tables, and dashboard visualization.

---

## 🧰 Tools Used
- SQL (Data querying & structure)
- Microsoft Excel (Pivot tables & dashboard)
- GitHub (Version control & documentation)

---

## 📁 Dataset Description
The dataset includes sales transaction data with:
- Customer information
- Product categories
- Sales amounts
- Country
- Order dates

---

## 📊 Analysis Performed
- Total sales calculation
- Sales by category
- Sales by country
- Customer-wise analysis
- Trend analysis using Excel Pivot Tables
